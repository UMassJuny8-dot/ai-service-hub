AI SERVICE HUB // FUTURE VERSION

실행
1) 폴더를 VS Code로 엽니다.
2) index.html을 Live Server로 실행합니다.
3) 최종 확인 후 이 폴더 내용을 Git 저장소에 넣고 commit / push 합니다.
4) Netlify에서 해당 저장소를 연결하면 정적 사이트로 배포됩니다.

주요 기능
- 미래형 HUD / 사이버 인터페이스 디자인
- 서비스 검색 / 분야 필터 / 요금 필터
- 직접 사용한 AI만 보기
- 서비스 상세보기
- 최대 3개 AI 비교
- 모바일 반응형
- 직접 사용 기록 편집

직접 사용 기록 편집 방법
1) 상단 '사용 기록 편집' 버튼을 누릅니다.
2) 각 카드에서 '써봄 표시'를 누르거나 상세보기에서 '직접 사용함'과 소감을 수정합니다.
3) 변경 내용은 해당 브라우저의 localStorage에 자동 저장되므로 새로고침해도 유지됩니다.

중요: 다른 사람에게도 보이게 공개 반영하려면
1) 편집 모드에서 '공개 반영 파일 저장'을 누릅니다.
2) 내려받은 usage-overrides.js 파일을 이 프로젝트의 js/usage-overrides.js에 덮어씁니다.
3) Git commit / push 합니다.
4) Netlify는 Git 저장소와 연결되어 있으면 자동 재배포됩니다.

배경 이미지

- 사용자가 제공한 참고 이미지를 사이트용 배경으로 최적화한 파일입니다.


[이번 버전 추가 사항]
- 각 AI 카드/상세보기/비교 화면에 서비스 아이콘 자동 표시
- 아이콘 로딩 실패 시 서비스명 이니셜로 자동 대체
- 사용자가 업로드한 최신 usage-overrides.js 반영
- 서비스 아이콘은 각 서비스 URL을 기준으로 Google favicon 서비스를 통해 로드
